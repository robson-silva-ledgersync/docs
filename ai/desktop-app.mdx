---

A few banks need the LedgerSync desktop app when the AI refreshes them. The app runs on a computer at your
firm.

**Which banks?** The AI tells you when a refresh needs the desktop app.

You set up the app once.

<Steps>
  <Step title="Get the app">
    Ask the AI: "Help me set up the LedgerSync desktop app." It gives you the download link for your computer.

    Or download it here:

    <CardGroup cols={2}>
      <Card title="Download for Windows" icon="download" href="https://api.fdels.com/api/v2/proxy/app/installator/download?os=windows&version=latest">
        LedgerSync desktop app for Windows.
      </Card>
      <Card title="Download for Mac" icon="download" href="https://api.fdels.com/api/v2/proxy/app/installator/download?os=macos&version=latest">
        LedgerSync desktop app for Mac.
      </Card>
    </CardGroup>

    Install it on a computer at your firm.
  </Step>
  <Step title="Get a code from the app">
    Open the app. Open **Settings**. Set **Connect with** to **AI chat**.

    The app shows a code of 7 letters and numbers.
  </Step>
  <Step title="Tell the AI the code">
    Type the code in the chat. The AI asks you to confirm. Say yes.

    The AI says **The desktop app is linked.**
  </Step>
</Steps>

<Note>
  Only one computer is connected at a time. Linking a new computer disconnects the old one.
</Note>

<Tip>
  **Keep that computer on and the app open.** The AI can refresh these banks only while the app is open.
  To check, ask: "Is the LedgerSync desktop app connected?"
</Tip>

Something went wrong with the code or the app? See [Troubleshooting](/ai/troubleshooting).

Stuck? Email [support@ledgersync.com](mailto:support@ledgersync.com) with the step and what the screen says.
Never send passwords or card numbers.
