import { AiPage, AiStep, AiButton, AiNote, AiStuck } from "/snippets/ai-ui.jsx";

<AiPage title="Banks that need the LedgerSync desktop app" subtitle="A few banks need the desktop app when the AI refreshes them. The AI tells you when a bank is one of them. You set it up once.">

<AiStep id="get-app" n={1} total={3} title="Get the app">

Ask the AI: *"Help me set up the LedgerSync desktop app."* It gives you the download link. Or download it
here:

<div className="lsai-buttons">
  <AiButton href="https://api.fdels.com/api/v2/proxy/app/installator/download?os=windows&version=latest">Download for Windows</AiButton>
  <AiButton href="https://api.fdels.com/api/v2/proxy/app/installator/download?os=macos&version=latest" outline>Download for Mac</AiButton>
</div>

Install it on a computer at your firm.

</AiStep>

<AiStep id="code" n={2} total={3} title="Get a code from the app">

Open the app. Open **Settings**. Set **Connect with** to **AI chat**. The app shows a code of 7 letters and
numbers.

</AiStep>

<AiStep id="tell-ai" n={3} total={3} title="Tell the AI the code">

Type the code in the chat. The AI asks you to confirm. Say yes. It says **The desktop app is linked.**

</AiStep>

<AiNote tone="gray">

**Keep that computer on and the app open.** The AI can refresh these banks only while the app is open. To
check, ask: *"Is the LedgerSync desktop app connected?"*

</AiNote>

<AiNote tone="gray">

**Linking a new computer replaces the old one.** Only one computer is linked at a time. Only your firm's
LedgerSync owner can link the desktop app; teammates can ask the AI whether it is connected.

</AiNote>

Something went wrong with the code or the app? See [Troubleshooting](/ai/troubleshooting).
